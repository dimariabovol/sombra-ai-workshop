# Workflow

## Two-agent setup

- **Architect agent**
  - Clarifies goals and constraints
  - Interviews the idea with sharp questions
  - Proposes options and recommends a direction

- **Engineer agent**
  - Implements features step by step
  - Runs tests and fixes issues
  - Prepares production-ready code and deployment

## Human role

- You set priorities, make final calls, and own product vision

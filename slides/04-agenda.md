# Agenda

## What we will do together

1. **Intention** -> Refine the product vision
2. **Plan** -> Define `v1`, `v2`, and future scope
3. **Interview** -> Challenge assumptions and fill gaps
4. **Approach** -> Compare options and pick one
5. **Build** -> Ship usable increments
6. **Review** -> Quality, maintainability, UX checks
7. **Deploy** -> Release and gather feedback
8. **Iterate** -> Feed learnings into next version
